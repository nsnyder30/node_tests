# Node Tests: Passport Module
This example implements authentication using the passport module. This reuqires a front-end with a login prompt that sends a POST request with <b>username</b> and <b>password</b> inputs to the '/login' route. This was originally written with an angular frontend which can be found <a href="https://github.com/nsnyder30/angular_tests/tree/passport">here</a>.
